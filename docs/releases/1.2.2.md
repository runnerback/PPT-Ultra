# PPT Ultra 1.2.2 — Enterprise security review hardening

PPT Ultra locks Python and npm dependencies, removes third-party mirror defaults and automatic browser installation, and adds explicit safety boundaries to both skill entrypoints. All engines, templates, icons, fonts and audio assets remain included.

## Highlights

- Python direct and transitive dependencies use exact versions and SHA-256 hashes; installation requires hashes and binary distributions.
- All 10 npm direct dependencies match exact lockfile versions. Installations use `npm ci --ignore-scripts` and the official or administrator-configured enterprise registry.
- P1–P4 instructions cover external material as data, presentation-only use, indirect prompt injection and sensitive information handling.
- Upload archives are split into independently verifiable volumes, with separate plaintext source review ZIPs and provenance manifests.

## What's new

- Browser provisioning moves to the host. The skill no longer downloads browser binaries from a mirror; use approved Chrome/Chromium through `CHROME_PATH` or an approved browser cache.
- Automatic Python workflow logs omit argument values and captured output; Themed failure telemetry records categories instead of raw error messages.
- Sponsorship files retain attribution without referral promotions. Environment examples use empty variables and a non-routable enterprise-gateway placeholder.
- Aggregate licensing is declared as AGPL-3.0 with bundled MIT components. MIT notices are retained, and integrity checks continue to reject altered licensing and attribution metadata.
- Release builds use the corresponding tag, controlled distribution file lists and locked installation. Review volumes, source hashes and source revision metadata are published with the installation packages.

## Upgrade notes

- Use `ppt-ultra-1.2.2-upload.zip` for the company skill form. Its root directly includes SKILL.md, dependencies and license metadata, readable guidance and bounded runtime volumes.
- Use `ppt-ultra-1.2.2.zip` for full-directory installation. Both restore the same engine and asset contents.
- Source review volumes are audit supplements, not standalone installation packages. They expose implementation/configuration/docs after one ZIP extraction; binary and SVG assets remain in the full package and runtime volumes.
- Default volume limit is 8,000,000 bytes. The scanner's actual limits and recursive counting rules still apply; company approval requires a fresh review.
- Browser-dependent checks need a host-provisioned browser. Optional plugins must also be approved and pinned by the host. Dependency hashes do not substitute for upstream vulnerability review or enterprise network controls.
- No existing local logs are deleted. Enforce company logging, credential and outbound-network policies in the host environment.
