# PPT Ultra 1.2.0 — Host contract: drive the skill from your own agent or pipeline

**1.2.0 turns PPT Ultra from a chat-only skill into something a bot or CI job can call.** A host writes one JSON brief, the skill produces a deck without asking questions or starting servers, and hands back a machine-readable manifest. This release also ships the 1.1.1 changes that were never tagged on their own.

## Highlights

- **Host contract** (`skills/ppt-ultra/host/`): `brief.schema.json` → `build_prompt.py` → agent run → `collect_manifest.py`. Decisions (route, pages, style, fonts, deliverable) are made by the host up front; the agent only designs and verifies.
- **Two host profiles**: `workflows/profiles/host-quick.md` (native, editable `.pptx`) and `workflows/profiles/host-editorial.md` (single-file HTML deck with presenter mode). Same brief, `deliverable: "pptx" | "html"`.
- **Cross-engine style table** `references/style-briefs/themes.json`: 21 themes, each with the HTML selection, the Native style brief and (for light themes) the Spec Native `style` block, generated from the engines' own sources, never hand-copied.

## What's new

### Host contract
- `host/brief.schema.json`: work dir, skill dir, python, deck meta, page total and per-page roster, style (visual style, mode, palette, fonts, body size, theme ref), materials and images, constraints, `must_keep` / `must_avoid`, `forbidden_strings` (hard-checked by program), revision feedback, output names.
- `host/build_prompt.py <brief> [-o out.md] [--check]`: validates the brief and renders a deterministic prompt; `--check` only validates.
- `host/collect_manifest.py <work_dir> [--brief] [--preflight] [--preflight-font <font>] [--pptx-name | --copy-as] [--deliverable pptx|html]`: collects `manifest.json` from the run directory without trusting the agent's own summary. PPTX mode: slide / native chart / table / font counts, quality-gate report, optional LibreOffice preflight PDF. HTML mode: slide count, leftover `[必填]` placeholders, speaker-note count, Editorial validators, grey-card-on-dark-page count, forbidden strings.
- `host/examples/` (pptx and html briefs) and `host/README.md` (integration in three steps, known facts about fonts and gateways).

### Workflows
- `workflows/profiles/host-quick.md`: Quick with decisions taken by the brief. Trimmed reading list, no questions, no servers, calibrated values × 0.9 margin, forbidden-string grep before export, revision on the same project.
- `workflows/profiles/host-editorial.md`: Editorial for hosts. Family / theme from the brief (built-in theme id or `gz-theme.mjs brand <color>`), theme rhythm planned first, speaker notes per slide, validators, single-file output. Rule added from a real run: no grey `.card-fill` on dark pages.
- `SKILL.md` runtime table, `routing.md` §8, `intake.md` §3 and `workflows/index.md` route a host brief to the right profile by its `deliverable`.

### Style briefs (from 1.1.1)
- `tools/build-style-briefs.mjs` generates `references/style-briefs/themes.json` from the Editorial theme table, Themed `theme-profiles.mjs` + `options.md` and Spec Native `pptx_style.py`. `intake.md` §2.1 cross-format mapping now reads the table instead of guessing colours from a style image; `spec-native.md` §4 and `spec-native-layouts.md` point to it.

### Tools and docs (from 1.1.1)
- `tools/upstream-check.sh` works on bash 3.2 (macOS default); `tools/upstream-pins.json` records the three upstream versions.
- NOTICE merge steps gained a pre/post check; USER_GUIDE FAQ (EN / zh-CN) lists which routes can produce `.pptx`.
- Spec Native origin note no longer names the author's employer product.
- `tools/smoke.sh` covers the host contract (pptx and html briefs, synthetic project, empty-dir error path, placeholder check).

## Lessons written into the contract
- The calibration font must be a font actually installed where the deck is rendered (on Linux hosts use Noto Sans CJK SC). The exporter maps CJK families to Microsoft YaHei; preflight renders a copy with `--preflight-font` to compare apples to apples.
- Some gateway models randomly reject long technical context (content inspection). Hosts should resume the same session rather than restart.
- Natural-language "do not write X" does not bind a model. Put it in `forbidden_strings` and let the program check.

## Upgrade notes
- No breaking changes for chat use. Existing Quick / Editorial / Themed / Spec routes are unchanged.
- Hosts need Python 3.10–3.14 with `pip install -r skills/ppt-ultra/requirements.txt`; Node ≥ 20 for the Editorial validators; LibreOffice optional for preflight PDFs; Graphviz `dot` optional for flow / swimlane / hierarchy layouts.
- If you consume `themes.json`, regenerate it with `node tools/build-style-briefs.mjs` after editing any engine's theme source.
