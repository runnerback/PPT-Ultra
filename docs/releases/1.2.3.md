# PPT Ultra 1.2.3 — Public distribution privacy hardening

This release removes optional maintainer contact details and unnecessary work-background descriptions, replaces sample contact domains with reserved `.example` domains, and adds automated privacy checks. All engines, layouts and assets remain available.

## Changes

- Keep author attribution and licenses while reducing optional personal information in public documentation and marketplace metadata.
- Update sample contacts consistently in Themed source metadata and prebuilt runtime bundles.
- Add tracked-file privacy checks, synthetic regression tests and a pinned, checksum-verified Gitleaks CI workflow. Reports omit matched sensitive values.
- Ignore additional local credential/configuration containers, and run privacy checks before formal release packaging.
- Update user guides to describe official or approved registry configuration.

## Verification and scope

Local checks cover current files, reachable Git history, dependency/security regression, style metadata consistency and lossless upload restoration. The two reviewed default Gitleaks findings are fixed PowerPoint animation identifiers; the configuration exempts only those exact values.

A new release does not erase old commits, commit-author metadata or earlier Release assets. Historical cleanup requires a separate coordinated migration. Detailed scope and limitations are documented in the repository's public privacy review.

## Assets

Use `ppt-ultra-1.2.3-upload.zip` for the file-count-limited skill form and `ppt-ultra-1.2.3.zip` for full-directory installation. Source review ZIP volumes, a provenance manifest and SHA256SUMS are published alongside them.
