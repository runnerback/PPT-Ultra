## 一、使用教程

### 1.1 开始之前

1. **新建一个空文件夹**作为工作目录，比如桌面上的 `我的PPT`。生成的文件都会放在这里。
2. 在这个文件夹里打开 AI 工具：
   - Claude Code / Codex 命令行：先 `cd` 到这个文件夹，再运行 `claude` 或 `codex`。
   - 桌面 App：在 App 里选择这个文件夹作为项目目录。
3. 有素材（PDF、Word、Excel、旧 PPT、图片）就先放进这个文件夹。

### 1.2 说出你的需求

直接用平常说话的方式描述就行。说得越清楚，AI 问得越少：

```text
帮我做一份 PPT：
- 主题：2026 年 AI 行业观察
- 用途：周五部门分享会，现场演讲 20 分钟
- 素材：文件夹里的「行业报告.pdf」
- 风格：杂志风
- 要演讲者模式
```

如果信息不全，AI 最多问你**两个问题**：

1. **做成什么格式？** 网页演讲 PPT / 汇报用（可导出 PDF）/ 可编辑的 .pptx
2. **用什么风格？** 杂志风、瑞士风，或 12 套主题（T01–T12）中选一套

不知道怎么选就回复"你帮我选"，AI 会按用途推荐。

### 1.3 三种成品，怎么用

#### A. 演讲网页 PPT（适合现场演讲、分享会）

- **成品**：一个 `.html` 文件，双击就能用浏览器打开，不联网也能放。
- **翻页**：方向键、空格，或鼠标滚轮。
- **演讲者模式**：AI 会告诉你如何打开。打开后，你的屏幕显示提词备注、下一页预览和计时，投影屏只显示幻灯片。常用快捷键：

  | 按键 | 作用 |
  |---|---|
  | `L` | 激光笔 |
  | `C` | 圈选标记 |
  | `X` | 清除标记 |
  | `B` / `W` | 投影屏黑屏 / 白屏 |
  | `F` | 冻结 / 恢复投影屏 |
  | `A` | 自动翻页开 / 关 |
  | `R` | 开始 / 结束排练计时 |
  | `?` | 查看全部快捷键 |

- 电脑性能弱、动画卡顿时，看右下角提示，按对应键切换"静态"模式。

#### B. 主题汇报 PPT（适合工作汇报、方案、报告）

- **成品**：AI 会在浏览器里打开一个预览页。
- **挑方案**：每一页都有 **4 个版本**（3 个模板方案 + 1 个 AI 定制方案），在右侧面板里切换，选中你喜欢的那个。
- **改内容**：直接在页面上编辑文字，修改会自动保存。
- **导出 PDF**：点预览页上的 **"导出 → PDF"**，文件会像普通下载一样保存到浏览器的下载文件夹。导出要在 AI 打开的预览页（地址以 `http://` 开头）里操作，直接双击 HTML 文件打开的页面不能导出。
- **成品 HTML**：在工作目录的 `output/<项目名>/ppt/index.html`。
- 这条路线**不提供 .pptx 导出**。需要 .pptx 请选 C。

#### C. 可编辑 .pptx（适合需要继续在 PowerPoint / WPS 里改的场合）

- 过程中 AI 可能在浏览器里打开一个**确认页**，让你确认设计方案后再继续，按页面提示操作即可。
- **成品**：在工作目录的 `projects/<项目名>/exports/` 里，文件名形如 `项目名_时间.pptx`。
- 打开后文字、形状、图表都可以直接编辑，不是图片。
- 还能做这些：
  - **套用公司模板**："用文件夹里的「公司模板.pptx」做一份产品介绍"
  - **美化旧 PPT**："把「旧方案.pptx」美化一下，内容和页数不要动"
  - **只改几页**："把第 3 页和第 5 页换成图表"
  - **生成讲解视频**："给这份 PPT 加上讲稿和配音，导出成视频"

#### D. 规格驱动的 .pptx（表格、图表多的汇报；批量或不能追问的场合）

- **怎么触发**：说"用规格模式 / 按规格 JSON 做""要确定性、可复现"，或者内容本身是大段表格、好几张图表、流程图 / 泳道图而不追求设计感，AI 会走 Spec Native 引擎。
- **过程**：AI 先列事实清单和页规划（交互时会让你确认一次），然后写一份 `spec.json`，校验通过后一条命令生成，整个过程只有几秒。
- **成品**：工作目录下 `<项目目录>/spec.json` 和 `<项目目录>/<名字>.pptx`；文字、表格、图表、流程图都是原生对象，可以继续改。
- **改法**：改意见会落到 `spec.json` 再重新生成，所以"把第 3 页换成表格""标题改成……"这类修改几秒就能出新版；规格文件也可以自己手改后让 AI 重跑。
- **风格**：想要杂志风 / 瑞士风某配色或 `theme01`–`theme12` 的观感，直接说主题名，AI 会把该主题的配色套进规格（只有浅底主题能套；暗底主题会提示改走 C）。
- **特点**：数值全一样的"示意图表"会被拒绝，正文里的 `[1]` 这类出处编号会自动变成上标并在最后加一页引用出处。需要套公司母版或追求设计师级版面时，请用 C。

### 1.4 不满意怎么改

直接告诉 AI 哪里不满意，越具体越好：

- "第 3 页文字太多，拆成两页"
- "整体配色换成蓝色系"
- "封面标题改成「智领未来」"
- "加一页团队介绍，放在结尾前"

每次生成后 AI 会对照需求逐项检查，结果只有三种：**通过 / 待修正 / 阻塞**。没达标时它会说明原因，不会假装完成。

### 1.5 提示词模板

复制后把【】里的内容换成你自己的：

```text
帮我做一份【主题】的 PPT。
用途：【现场演讲 / 领导汇报 / 发给客户看 / 课程讲义】
时长或页数：【15 分钟 / 10 页左右】
素材：【文件夹里的 xxx.pdf / 下面这段文字 / 你帮我调研】
格式：【网页 / PDF / 可编辑 PPTX】
风格：【杂志风 / 瑞士风 / theme05 / 用公司模板 / 你帮我选】
其他要求：【要演讲者备注 / 要配图 / 要数据图表】
```

## 二、常见问题

**Q：AI 说找不到 ppt-ultra 技能？**
检查三点：① 复制的是 `ppt-ultra` 文件夹本身，打开能直接看到 `SKILL.md`；② 放对了目录（见 README 的[安装](../README.zh-CN.md#安装)）；③ 复制后重启了 AI 工具。

**Q：提示 `python` / `node` 命令不存在？**
对应的运行环境没装好，或安装时没加入 PATH。按 README 的[准备工作](../README.zh-CN.md#第-0-步准备工作所有工具通用)重新安装，装完后**重新打开终端或 AI 工具**。

**Q：提示缺少 Python 模块（ModuleNotFoundError）？**
没装 Python 依赖。对 AI 说"帮我安装 ppt-ultra 的 Python 依赖"，或在技能包目录执行 `pip install -r requirements.txt`。

**Q：主题汇报 PPT 第一次生成特别慢？**
第一次要自动下载 Node.js 依赖，网络慢时需要几分钟，之后就快了。国内网络可以先设置镜像：`npm config set registry https://registry.npmmirror.com`。

**Q：点"导出 PDF"提示需要预览服务？**
你打开的是本地文件（地址以 `file://` 开头）。对 AI 说"帮我重新打开预览页"，在它给出的 `http://` 地址里导出。

**Q：能导出 .pptx 的有哪些路线？**
C 路线（可编辑 .pptx）和 D 路线（规格驱动 .pptx）。A、B 两种网页路线分别交付 HTML 和 PDF。想要网页的风格又要 .pptx，直接说"要杂志风的 PPTX"，AI 会把风格转交给 .pptx 引擎。D 路线只有流程图 / 泳道图 / 层次树三种页需要系统装 Graphviz（`dot`），其余版式只靠 Python 依赖就能跑。

**Q：生成的内容准确吗？**
AI 会尽量依据你提供的素材。涉及数据、日期、人名等关键信息，发出去之前请自己核对一遍。

**Q：收费吗？**
PPT Ultra 本身免费开源（AGPL-3.0）。费用来自你使用的 AI 工具或模型服务，以及可选的生图服务。

**Q：怎么更新到新版本？**
插件安装的：在 Claude Code 里输入 `/plugin` 进入插件管理更新。手动安装的：重新下载，删掉旧的 `ppt-ultra` 文件夹，再复制新的进去。
