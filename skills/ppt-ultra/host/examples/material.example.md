# 智能音箱 Q3 运营复盘 · 材料

> 虚构数据，仅作示例。

## 一句话

Q3 月活跃设备 126 万，环比增长 18%；语音识别成功率 94.2%，较 Q2 提升 1.8 个百分点；下季度重点是留存与渗透。

## 关键数字（2026-10-15 口径）

| 指标 | 值 | 对比 |
|---|---|---|
| 月活跃设备 | 126 万 | 环比 +18% |
| 日均语音请求 | 1,860 万 | 环比 +22% |
| 语音识别成功率 | 94.2% | 较 Q2 +1.8 pct |
| 新用户 7 日留存 | 46% | 目标 50% |
| 付费内容渗透率 | 9% | 目标 12% |

## 增长来源

- 7 月促销带来 31% 的新增设备；
- 儿童模式上线后家庭用户占比从 38% 升到 47%；
- 音乐与儿童内容合计占请求量 61%。

## 问题

1. 留存与渗透率两项低于季度目标；
2. 老设备（2024 年前）识别成功率 89%，拉低整体；
3. 客服工单里「听不懂方言」占 23%。

## 下季度三件事

1. 老设备语音模型升级，目标成功率 93%；
2. 新用户 7 日留存做到 50%：首周任务 + 家庭共享；
3. 付费内容渗透到 12%：儿童会员与音乐包联动。
